# 页面设计规范：SaaS 商家工作台 — 工作流引擎 (Workflows)

- **页面路径**：`/console/workflows`
- **页面定位**：自动化触达引擎，编排待支付挽回与 COD 校验规则、国家区号多语言自动分流器、静默时段排期、频次风控与版本回退
- **设计基调**：纯白底色、深黑铅印、1px 发丝几何线、严禁蓝紫色系
- **当前工作语言**：中文 (`zh_CN`)，支持切换为英文 (`en_US`)

## 3. 核心字段与业务不变量 (PRD 严格对齐)

1. **自动取消机制（Auto-Revocation）**：
   - 待支付挽回规则进入延时队列后，若在 15 分钟窗口期内收到商城的 `order.paid` 或 `payment.complete` Webhook，引擎必须**原子撤销排队任务**，绝不可在买家已付款后仍发送催付消息。
2. **静默时段强制时区校验**：
   - 静默时段必须依据店铺实际所在国家/时区（如印尼西部时区 `WIB / UTC+7`）执行，禁止使用商家本地电脑的时间。
3. **版本回退机制**：
   - 每次规则修改产生只读快照版本（如 `v1.0` -> `v1.1`），历史抽屉记录每次变更人与变更时间，支持“一键回退到此版本”。

## 4. 状态覆盖与交互行为

| 状态 | 表现规范 |
| :--- | :--- |
| **Loading** | 抽屉或卡片列表显示细边框骨架条，加载时间保持低于 200ms。 |
| **Empty** | 若商户关闭所有规则，主界面顶部出现发丝黄框（`#D97706`）提示：“所有自动化工作流处于暂停状态，系统暂不发送任何挽回消息”。 |
| **Error** | 若规则保存时模板缺少对应的多语言分支，表单字段下方弹出红字提示，并阻止保存。 |
| **Success** | 规则启停开关采用纯黑白滑动切换，切换成功后右上方淡出 2 秒微吐司提示：“规则已应用，新入站订单立即生效”。 |
