## 2. 核心模块精细化视觉与交互规范

### 2.1 顶部导航栏 (Navbar) 与语言切换胶囊
- **容器规格**：固定于视口顶部，高度 `64px`，背景 `rgba(255, 255, 255, 0.92)`，底部 `1px solid #E4E4E7`，毛玻璃 `backdrop-blur: 12px`。
- **语言切换胶囊**：
  - 位于导航栏正中偏左，外框 `border: 1px solid #E4E4E7; border-radius: 9999px; padding: 2px;`。
  - 选项包含 `EN`、`ID`、`中文`。
  - 选中态：背景 `#09090B`，文字纯白 `#FFFFFF`，圆角胶囊滑块平滑弹性过渡（Spring 物理动画，`duration: 0.2s`）。
  - 未选态：背景透明，文字 `#71717A`，悬停时文字变为 `#09090B`。
  - **语言联动响应**：
    - 切换为 `ID` 时：Hero 标题变为 “Asisten Pesanan WhatsApp Otonom”，沙盒默认高亮印尼语雅加达真实案例。
    - 切换为 `EN` 时：Hero 标题变为 “Autonomous WhatsApp Agents for Southeast Asian Commerce”。
    - 切换为 `中文` 时：展示针对中国出海卖家的痛点视角文案。

### 2.2 3D 单色拓扑地貌雕塑 (Three.js Monochromatic Topo-Mesh)
- **画布位置**：位于 Hero 区域右侧及全屏背景底层（`z-index: 0`），绝对禁止遮挡主标题文字。
- **几何与着色**：
  - 网格基于参数化高斯噪声与东南亚经纬度地形生成，顶点数控制在 12,000 以内保证低端机流畅度。
  - 材质：`THREE.LineBasicMaterial({ color: 0x18181B, linewidth: 1.0, transparent: true, opacity: 0.85 })`。
  - 画布底色：纯透明，透出纯白页面底层 `#FFFFFF`。
  - 坐标标记：在 CGK (雅加达)、BKK (曼谷)、SIN (新加坡) 经纬度位置标注等宽代码字体微标签（`font-mono text-[10px]`）。
- **交互与降级**：
  - 鼠标移动产生轻微的动力学凹陷（Damping 系数 `0.05`），如纸张受压微张力形变。
  - 页面向下滚动超出 `100vh` 后，自动调用 `cancelAnimationFrame` 停止渲染循环，节省 GPU 资源。
  - 移动端（`< 768px`）或检测到 `prefers-reduced-motion: reduce` 时，自动平滑降级为高精度单色 SVG 发丝线轮廓矢量图。

### 2.3 双向实时遥测沙盒 (Dual-Telemetry Sandbox)
沙盒采用如航天工业控制台般的分屏对比布局：
1. **左侧：真实 WhatsApp 手机视窗**
   - 尺寸：宽度 `360px`，外框 `1px solid #E4E4E7`，背景纯白 `#FFFFFF`。
   - 顶部标头：官方商业账号绿色对勾认证图标（`#059669`），状态显示 “Official Business Account”。
   - 气泡排版：
     - 买家消息：浅灰底色 `#F4F4F5`，文字 `#09090B`，左对齐。
     - Bot 消息：纯白底色带 `1px solid #E4E4E7`，右对齐。
     - 交互胶囊：发丝线框按钮，鼠标点击时带有按压触感下沉微动效（`scale(0.97)`）。
2. **右侧：SolaFlow 神经决策脑遥测视窗**
   - 尺寸：与左侧等高，背景 `#FAFAFA`，内部分割采用 `1px solid #E4E4E7`。
   - 实时数据流分为 4 个精密仪器框：
     - **语言与方言雷达**：显示检测语言、可信度置信区间及俚语匹配项。
     - **COD 履约风险评分表**：刻度条（0~100），高危红点/低危黑点指示。
     - **店铺 Webhook 同步状态**：实时打印订单状态流转 JSON 片段。
     - **Solana Pay L1 凭证**：展示 Devnet 交易签名（可直接点击跳转 Solana Explorer）。

### 2.4 跨境 ROI 利润恢复计算器
- **排印规范**：采用金融年报风格，去除所有花哨图表与杂色柱状图，纯靠黑铅数字与发丝网格表达。
- **动态交互控制**：
  - 3 个原生 `input[type="range"]` 定制样式：滑块轨道为 `2px solid #E4E4E7`，滑块点为 `16px` 纯黑圆形 `#09090B`。
- **数学模型与输出公式**：
  $$\text{每月挽回 GMV} = \text{月订单量} \times \text{弃购率 (默认 68%)} \times \text{AOV} \times \text{SolaFlow 挽回转化率 (18.4\%)}$$
  $$\text{物流截流防损} = \text{月订单量} \times \text{COD 占比 (45%)} \times \text{拒签率 (18%)} \times \text{单均往返物流损耗 (\$6.5)} \times \text{拦截率 (34.4\%)}$$
  $$\text{ROI 净倍数} = \frac{\text{挽回 GMV} + \text{物流防损}}{\text{SolaFlow 预估服务费}}$$
- **金额数字滚动**：数值变化时采用单字符纵向滚动槽（Number Ticker）动效，时长 `180ms`。

### 2.5 Solana Pay 极简票据模态框
- **触发机制**：点击导航栏或页面 CTA 中的“Solana Pay 充值”按钮。
- **模态框视觉**：居中弹出，尺寸 `420px`，背景 `#FFFFFF`，边框 `1px solid #18181B`（高对比），带柔和环境投影。
- **票据要素**：
  - 顶部等宽字头：`SOLAFLOW BILLING // SOLANA PAY DEVNET`
  - 纯黑矢量 QR 码：`200x200px`，清晰扫描标准。
  - 链上关键参数：USDC 金额、收款人公钥、Reference 唯一哈希、预计 Gas（`0.000005 SOL`）。
  - 操作按钮：`[ 立即模拟 400ms 链上确认 ]` 纯黑全宽按钮。
- **Web Audio 微交互**：
  - 点击按钮播放 30ms 原生高精度快门音（`800Hz -> 200Hz`）。
  - 确认入账瞬间播放纯净双音共鸣完成音（`523.25Hz -> 1046.5Hz`）。

## 3. 页面状态与错误处理

| 状态 | 表现形式与界面交互 |
| :--- | :--- |
| **初始加载 (Initial)** | 页面首屏立即呈现纯文本骨架与排版流，3D 网格异步初始化，无整页白屏菊花。 |
| **沙盒场景切换** | 切换 Tab 时，左侧手机视窗与右侧遥测数据以 120ms 交叉淡入（Cross-fade），不抖动高度。 |
| **Solana 链上轮询** | 模态框底部显示 `STATUS: POLLING_TX_SIGNATURE (1.2s)`，若超时展示重试按钮与工单指引。 |
| **WebGL 异常降级** | 当浏览器不支持 WebGL 时，控制台捕获异常并无缝替换为单色高精度矢量几何静态图，不抛出任何前端报错。 |

## 4. 响应式断点与移动端适配

- **桌面端 (1440px+)**：双栏沙盒并排完整展现，3D 拓扑网格全尺寸渲染。
- **平板端 (768px ~ 1439px)**：沙盒保持双栏并排但收窄内边距，ROI 计算器由三列排版自适应调整为上下堆叠。
- **移动端 (375px ~ 767px)**：
  - 导航栏折叠为极简汉堡菜单与纯黑抽屉。
  - 沙盒切换为移动端 Tab 选项卡（在“买家视窗”与“遥测引擎”间横向滑动切换）。
  - 3D 拓扑网格降级为静态单色发丝背景，保证长页面滚动 60fps 丝滑流畅。
