# 页面设计规范：SaaS 商家工作台 — 店铺与通道 (Store & Channel)

- **页面路径**：`/console/stores`
- **页面定位**：管理出海电商店铺（WooCommerce / Shopify）授权绑定与 WhatsApp Business 商业号码通信质量、模板审核矩阵与通道自测
- **设计基调**：Modern Enterprise B2B SaaS（现代企业级商业规范、清晰稳健、高数据密度与专业工作台交互）
- **当前工作语言**：中文 (`zh_CN`)，支持切换为英文 (`en_US`)

## 2. 字段规范与核心数据逻辑

### 2.1 电商店铺授权解绑确认弹窗 (Danger Modal)
- 解绑属于高危操作，严格禁止点击一次即生效。
- 点击“解除授权”呼出极简居中黑白确认卡片：
  - 警告说明：“解除绑定将立即中止所有排队中的 WhatsApp 提醒与 COD 校验，买家将无法收到最新物流提醒。”
  - 强制输入验证：商户必须在输入框内键入当前店铺名称 `TokoSepatu_ID` 才能激活纯黑确认解绑按钮。

### 2.2 WhatsApp 模板审核矩阵字段规约 (Meta Cloud API 对齐)
- **模板类别**：
  - `Marketing`：15 分钟待支付弃购挽回。需注意：Meta 按营销类模板向商户扣费，且必须包含退出退订（Opt-out）选项。
  - `Utility`：COD 发货前地址确认、物流状态变更通知。单价较低，履约相关。
- **模板语言分支**：
  - 每个模板卡片支持横向展开查看 `id_ID`、`en_US` 与 `th_TH` 的具体文案映射。
  - 包含动态插值占位符：`{{1}}`（买家姓名）、`{{2}}`（商品名称）、`{{3}}`（金额/运费）、`{{4}}`（快速确认短链接）。

## 3. 状态覆盖与交互行为

| 状态 | 表现规范 |
| :--- | :--- |
| **Loading** | 表格每一行展示发丝线浅灰骨架屏（高度 `40px`），保持表头稳固。 |
| **Empty** | 若商户未绑定店铺，展示大号发丝虚线框：“暂无已绑定出海店铺，支持一键连接 WooCommerce / Shopify”，并提供纯黑引导按键。 |
| **Error** | 若 WhatsApp API 评级降为 `Low` 或发生验签失败，卡片顶部拉起 1px 发丝红框条（`#E11D48`），提供“重新生成 Webhook Token”操作。 |
| **Success** | 模板状态显示绿色指示小圆点（`#059669`），测试沙盒在收到 `DELIVERED` 状态后自动轻触提示。 |

## 4. 响应式与可访问性

- **断点自适应**：
  - 1440px+：表格全宽平铺，模板矩阵展示全部参数列。
  - 768px~1439px：操作按钮收折进下拉菜单操作项（More Options）。
  - 375px：模板表格降级为单卡片垂直堆叠模式，保证字段不被截断。
- **a11y 规范**：解绑确认输入框带自动聚焦（`autoFocus`），按 `Escape` 立即取消并恢复原焦点。
