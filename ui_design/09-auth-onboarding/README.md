# 页面设计规范：SaaS 入驻向导 — 注册登录与 6 步激活 (Auth & Onboarding)

- **页面路径**：`/login`, `/onboarding`
- **页面定位**：商户入驻接入、免密邮箱鉴权、严格对齐 PRD 3.1 的 6 步激活向导与 100 Credits 试用额度发放

- **当前工作语言**：中文 (`zh_CN`)，支持切换为英文 (`en_US`)

## 4. 异常阻断与边界保护

- **未满足条件禁止跳步**：
  - 若步骤 5（仿真演练）中模拟付款未能触发原子撤销，步骤 6 将显示红字阻断卡片：`[X] 仿真测试未通过：付款后未撤销排队任务`，严禁商户开启真实自动化，防止生产环境对已付款买家产生骚扰。
- **防止重复冒领试用**：
  - 同一已验证的 WooCommerce 域名或 WhatsApp 业务号码仅能领取一次 100 Credits 试用额度。
