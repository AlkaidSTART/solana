# 页面设计规范：SaaS 商家工作台 — 报表与设置 (Analytics & Settings)

- **页面路径**：`/console/settings`
- **页面定位**：指标归因口径说明、20% 对照组实验配置、多语言偏好、团队 RBAC 权限管理以及数据合规导出与买家隐私删除
- **设计基调**：Modern Enterprise B2B SaaS（现代企业级商业规范、清晰稳健、高数据密度与专业工作台交互）
- **当前工作语言**：中文 (`zh_CN`)，支持切换为英文 (`en_US`)

## 2. 团队 RBAC 权限矩阵细化规范

| 角色 | 权限范围与页面可见性 |
| :--- | :--- |
| **所有者 (Owner)** | 拥有全站最高权限：店铺绑定/解绑、Solana Pay 充值、工作流规则启停、成员邀请与注销。 |
| **管理员 (Admin)** | 可管理店铺配置、工作流、知识库审核、订单审核，但不可解绑主店铺或变更组织所有权。 |
| **客服 (Agent)** | 仅可见【订单中心】、【会话与人工队列】，可进行人工接管沟通与 COD 改址提交，**不可查看财务流水与修改自动化规则**。 |
| **财务 (Finance)** | 仅可见【监控总览】、【财务充值中心】及【报表】，可进行 Solana Pay 充值与流水对账，不可介入客服对话。 |

## 3. 买家隐私擦除确认流程 (Right to be Forgotten)

- 依据东南亚当地数据保护条例及 Meta 开发者规范，买家发起退订或删除数据诉求时，商户必须具备彻底擦除能力。
- 点击“申请彻底擦除”呼出高危确认卡片：
  - 强制输入口令 `DELETE-DATA` 激活按钮。
  - 擦除范围：清空 PostgreSQL 中该买家的所有入站/出站聊天文本、收件地址与姓名，仅在财务审计账本中保留不可逆哈希值用于计费对账。

## 4. 状态覆盖与交互行为

| 状态 | 表现规范 |
| :--- | :--- |
| **Loading** | 成员表格呈现浅灰骨架屏，表单字段保持禁用态直至配置数据加载完毕。 |
| **Empty** | 暂无自定义设置项时，默认展示官方推荐默认配置（如 14 天观察期、印尼西部时区）。 |
| **Error** | 邀请成员邮箱格式错误或已存在时，输入框变深黑并带发丝红底线提示。 |
| **Success** | 设置变更保存后，表单右上方呈现 2 秒“设置已持久化保存”提示，无需全页重新加载刷新。 |
