# 页面设计规范：SaaS 商家工作台 — 订单中心 (Orders)

- **页面路径**：`/console/orders`
- **页面定位**：订单全生命周期监控、原平台同步状态审计、SolaFlow 自动化触达进度追踪与 COD 发货前改址/确认核实中心
- **设计基调**：纯白底色、深黑铅印、1px 发丝几何线、严禁蓝紫色系
- **当前工作语言**：中文 (`zh_CN`)，支持切换为英文 (`en_US`)

## 3. 字段规范与业务规则

1. **消息状态严格区分（PRD 3.2 强制规则）**：
   - 必须精确区分 `排队中 (QUEUED)`、`平台已接受 (ACCEPTED)`、`已发送 (SENT)`、`已送达 (DELIVERED)`、`已读 (READ)`、`失败 (FAILED)`、`未知 (UNKNOWN)`。
   - **绝对禁止将 API ACCEPTED 或 SENT 误标为已送达**；只有在收到 WhatsApp 明确的 `delivered` Webhook 后才能标记为已送达，并完成扣除 1 Credit 动作。
2. **脱敏保护**：
   - 买家手机号码默认进行隐私脱敏展示（例如 `+62 813-1102-**45`），点击旁边“小眼睛”按钮经权限校验后方可展示完整明文。
3. **改址同步幂等性**：
   - 点击“同意改址并同步回 WooCommerce”后，操作按钮立即进入 Loading 禁用态，防止多次并发点击造成电商平台地址重复覆盖。

## 4. 状态覆盖与交互行为

| 状态 | 表现规范 |
| :--- | :--- |
| **Loading** | 表格数据呈现 5 行淡灰发丝骨架屏，抽屉内步进器呈现脉冲灰色圆点。 |
| **Empty** | 筛选无结果时，提示“未找到符合当前条件的订单，请尝试调整筛选范围”，并附带“清除全部筛选”按钮。 |
| **Error** | 若订单详情拉取失败，抽屉内部显示“无法读取订单详情（错误码: ORD_SYNC_404）”，附带“重新加载”按键。 |
| **Success** | 改址成功后，表格对应行的 COD 确认结果立即平滑刷新为 `[● 已改址确认]`，状态指示灯为深绿色。 |
