# 页面设计规范：SaaS 商家工作台 — 监控总览 (Overview)

- **页面路径**：`/console`
- **页面定位**：商家每日进入的首屏，监控通道健康度、待办积压、Credits 额度，并展示严格对齐 PRD 2.3 的 20% 对照组真实催付增量效果
- **设计基调**：Modern Enterprise B2B SaaS（现代企业级商业规范、清晰稳健、高数据密度与专业工作台交互）
- **当前工作语言**：中文 (`zh_CN`)，支持切换为英文 (`en_US`)

## 2. 字段规范与核心数据逻辑

### 2.1 顶部状态指示灯 (Status Tickers)
- **WhatsApp Cloud API**：
  - 绿色圆点（`#059669`）：正常连通，质量评级 High。
  - 黄色圆点（`#D97706`）：告警，质量评级降为 Medium 或有重试积压。
  - 红色圆点（`#E11D48`）：阻断，凭证失效或 Meta 账户被限流。
- **电商店铺 Webhook**：展示同步健康度，若最近 15 分钟无心跳或签名错误即亮红灯。
- **Solana RPC**：展示 L1 通信延迟（正常 `< 600ms`）。

### 2.2 20% 对照组效果模型看板 (PRD 2.3 强制规则)
- **业务约束**：
  - 绝不可仅展示一个孤立的“提升率”，必须同时展示**提醒组（80%）**与**自然对照组（20%）**的基线数据。
  - 新接入店铺样本量不足（`< 200 单`）或处于观察期时，状态标签显示 `[ 样本积累中 (已观察 42/200 单) ]`，增量值显示为 `待观察`，绝不虚构数据。

### 2.3 新手零数据引导状态 (Zero-Data State)
当商家尚未接入店铺或未完成 WhatsApp 绑定时，总览隐藏指标大盘，居中展示发丝线虚线向导框：
```

```

## 3. 状态覆盖与交互行为

| 状态 | 表现规范 |
| :--- | :--- |
| **Loading** | 4 块指标卡片与对照组大盘呈现灰色发丝线骨架，闪烁周期 1.5s，高度不抖动。 |
| **Empty** | 触发上述【新手零数据引导状态】，主 CTA 按钮为纯黑底高反文字。 |
| **Error** | 若后端指标服务暂不可用，指标卡片内显示 `— —`，卡片右上角带 1px 细红点与“点击重试”按钮。 |
| **Success** | 完整渲染真实数据，右上角每 30 秒无感静默拉取更新，更新时数字带 100ms 微微淡入。 |

## 4. 响应式与可访问性

- **断点自适应**：
  - 1440px+：4 卡片横排，对照组大盘双列并排。
  - 768px~1439px：4 卡片变为 2x2 网格，对照组大盘单列纵向展开。
  - 375px：4 卡片纵向堆叠，字体等比例调整（数值字号降至 `text-2xl`），保证不横向滚动。
- **键盘导航**：按 `Tab` 键可依次聚焦各高危待办条目，回车键直接弹出抽屉处理。
