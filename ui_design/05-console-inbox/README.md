# 页面设计规范：SaaS 商家工作台 — 会话与人工队列 (Inbox & Human Handover)

- **页面路径**：`/console/inbox`
- **页面定位**：高密度三栏客服中心、WhatsApp 24 小时服务窗口倒计时监控、AI 与人工接管状态机、买卖双向实时翻译抽屉与印尼俚语高亮词典
- **设计基调**：Modern Enterprise B2B SaaS（现代企业级商业规范、清晰稳健、高数据密度与专业工作台交互）
- **当前工作语言**：中文 (`zh_CN`) ↔ 印尼语 (`id_ID`) / 英语 (`en_US`)

## 2. 核心交互机制与多语言翻译规范

### 2.1 买卖双向实时翻译抽屉 (Bi-directional Translation)
1. **买家侧到商家侧（入站即时译）**：
   - 买家输入印尼语（含口语及缩写），系统即时展示原声气泡，并在气泡下方提供高对比度中文翻译，词汇对齐准确率 $\ge 98\%$。
2. **商家侧到买家侧（出站回译预览）**：
   - 出海客服直接在输入框中键入中文。
   - 系统使用微型大语言模型实时生成针对东南亚本地电商语气的印尼语（如尊称使用 `Kak`，亲切得体），客服确认无误后点击“发送印尼语”，消息通过 WhatsApp Cloud API 触达买家。
3. **印尼本土俚语悬浮解析词典卡片 (Slang Hover Tooltip)**：
   - 气泡中命中的缩写词汇（`Gan`、`Ongkir`、`Cod-an`、`Gak`、`Nego`、`Jaksel`）带有极细虚线下划线。
   - 鼠标悬停时，弹出纯白底色（`#FFFFFF`）、发丝黑边（`#18181B`）的 Tooltip，显示完整标准词汇与业务含义。

### 2.2 WhatsApp 24 小时客户服务窗口倒计时规范 (PRD 5.3 严格对齐)
- **业务约束**：根据 Meta 规则，自买家最后一次发送消息起，商户享有 24 小时自由客服对话窗口。
- **UI 呈现**：
  - 剩余时间 `> 6 小时`：中灰文字显示 `剩余 18h 42m`。
  - 剩余时间 `2 ~ 6 小时`：发丝黄色标签（`#D97706`）显示 `剩余 3h 10m`。
  - 剩余时间 `< 2 小时`：发丝红色标签（`#E11D48`）闪烁告警 `窗口临界: 48m`。
  - **窗口关闭后**：输入框自动切换为禁用态，提示：“24 小时客服窗口已关闭。无法发送自由文本，需使用 Meta 获批模板重新唤醒买家”，并提供模板选择入口。

### 2.3 人工接管状态机 (PRD 5.4 强制规范)
| 状态机取值 | UI 状态展示 | 业务行为与规则约束 |
| :--- | :--- | :--- |
| `automated` | `[● AI 自动处理中]` (黑字灰底) | AI 依据知识库自动响应，客服可实时旁路观察。 |
| `waiting_human` | `[▲ 待人工接管 (排队中)]` (黄标) | 触发条件：买家要求人工、投诉退款、改址、或 AI 达到 20 条消息上限。**原子暂停 AI**，进入队列等待。 |
| `human_active` | `[● 人工处理中 (Alice)]` (绿标) | 由指定客服人员接管锁定，其他客服只读。AI 保持休眠。 |
| `resolved` | `[○ 会话已解决]` (灰标) | 客服处理完毕后标记解决。新消息入站前继续保持停止自动化。 |

## 3. 状态覆盖与交互行为

| 状态 | 表现规范 |
| :--- | :--- |
| **Loading** | 中间聊天视窗显示聊天气泡骨架条，右侧侧栏显示买家画像骨架卡片。 |
| **Empty** | 左侧会话列表为空时，展示“当前暂无待处理会话，所有消息均已妥善响应”，配以极简微插图。 |
| **Error** | 若发送消息失败（例如买家阻断接收或网络超时），气泡右侧展示发丝红色叹号，提供“点击重新发送”按钮。 |
| **Success** | 消息发送成功瞬间，气泡角落展示单灰勾标（`SENT`）-> 双灰勾标（`DELIVERED`）-> 双绿勾标（`READ`）。 |
