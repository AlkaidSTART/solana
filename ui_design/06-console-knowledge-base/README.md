# 页面设计规范：SaaS 商家工作台 — 知识库管理 (Knowledge Base)

- **页面路径**：`/console/knowledge`
- **页面定位**：东南亚多语言智能客服大脑，自动同步电商商品规格、四列多语言对照编辑器、跨语言知识冲突检测与管理员审核流
- **设计基调**：纯白底色、深黑铅印、1px 发丝几何线、严禁蓝紫色系
- **当前工作语言**：中文 (`zh_CN`)、印尼语 (`id_ID`)、英语 (`en_US`)、泰语 (`th_TH`)

## 2. 核心编辑交互与多语言矩阵规范

### 2.1 四列多语言对照编辑器 (4-Column Multilingual Matrix)
- **编辑交互**：
  - 点击任意单元格进入行内即时编辑状态，边框变为高对比纯黑发丝线（`#18181B`）。
  - 支持“AI 智能补全其它语言”：修改中文源文后，印尼语、英语和泰语输入框右上方出现小胶囊按钮 `[ 生成建议 ]`，点击后无缝填充符合本地电商语气的回译译文。
- **变量保护与敏感词拦截**：
  - 金额占位符（如 `Rp 300.000`）在各语言中必须数值一致。
  - 印尼语中严禁将通用尊称错译或混用（系统强制对齐尊称 `Kak` 或 `Agan`）。

### 2.2 跨语言事实冲突检测算法 (Conflict Detection)
- **业务依据（PRD 3.2 & 5.3 节）**：AI 回复买家前必须进行事实来源校验。若知识库内部存在不同语言的冲突项，严禁 AI 凭直觉胡乱承诺。
- **UI 预警机制**：
  - 命中冲突时，导航栏知识库标签立即出现发丝黄色角标 `[ 2 ]`。
  - 存在未解决冲突的词条在客服会话中心被临时标记为 `[ 暂停自动检索 ]`，买家咨询该问题时直接安全流转至人工客服。

## 3. 状态覆盖与交互行为

| 状态 | 表现规范 |
| :--- | :--- |
| **Loading** | 矩阵表格每行展现四列等宽浅灰骨架屏，加载平滑过渡。 |
| **Empty** | 若无 FAQ，展示“暂无自定义 FAQ，系统当前已自动索引 WooCommerce 1,240 件商品信息”，提供快速添加模版。 |
| **Error** | 商品同步失败时，顶部展示红线卡片说明“WooCommerce REST API 凭据已过期，请前往【店铺与通道】重新验签”。 |
| **Success** | 批量审核发布通过后，状态指示灯由黄转绿（`#059669`），右下角提示“知识库已成功同步至生产推理引擎”。 |
