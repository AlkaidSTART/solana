# 需求计划：规范 AGENTS.md 的 MVP 工作流

- 日期：2026-10-07
- 背景：当前 `AGENTS.md` 只有 Next.js 规则，缺少新需求的前置计划、阶段验证记录和最小交付约束。
- 目标：新需求开始前完成计划文档；每完成一个阶段更新根目录 `result.md` 的 checklist，记录完成内容及测试样例；每个需求按小型 MVP 闭环交付。
- MVP 范围：新增协作规则、此次计划文档及结果记录。
- 非目标：不修改业务代码或 Next.js 自动维护的规则区块，不引入测试框架。

## 最小可交付成果与验收标准

1. `AGENTS.md` 明确要求在编码前创建完整计划，写明目标、MVP 范围、阶段、验收条件与测试样例。
2. `AGENTS.md` 明确规定每阶段完成立即更新根目录 `result.md`，以 checklist 描述完成内容和测试样例的预期/实际结果，失败或未运行也如实记录。
3. 明确单个需求完成条件：MVP 可用、测试执行并记录、验收标准逐项核对；不达标不能标记完成。
4. 保留 Next.js 自动维护的规则区块和用户现有改动。
