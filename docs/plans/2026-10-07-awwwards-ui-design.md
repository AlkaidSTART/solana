# 需求计划：SolaFlow AI 出海产品 Awwwards 级 UI 设计规范

- **日期**：2026-10-07
- **Slug**：`awwwards-ui-design`
- **状态**：视觉方向修订执行中
- **方向修订**：根据用户明确要求，视觉彻底转向“白底黑字、极简大气、严禁蓝紫色系”，采用国际顶级极简编排（Swiss International Typography / Architectural Monochrome / Stripe Press 级克制美学）。

## 1. 需求目标与背景
根据东南亚跨境电商出海产品的业务诉求（`docs/PRD.md`），制定达到 Awwwards 评审标准的完整 UI 设计规范文档。当前阶段只输出 UI 设计文档。
视觉规范由暗色赛博风格重构为**白底黑色、极简大气、纯净克制**的国际化高奢商务风格，彻底剔除蓝紫渐变与霓虹发光等非必要修饰。

## 2. MVP 范围及非目标
- **MVP 范围**：
  - 更新 `docs/UI_DESIGN.md`：
    1. 确立“纯白基底、深黑铅字、极细发丝线、大面积留白”的极简高级视觉体系（Monochrome Editorial）。
    2. 彻底移除蓝紫色系（如 `#9945FF`、`#00C2FF`、赛博朋克词汇与霓虹渐变）。
    3. 重构色彩令牌：以 `#FFFFFF`、`#F8F9FA`、`#09090B`、`#18181B`、`#71717A` 为主，保留极少量功能性翡翠墨绿（`#059669` / `#10B981` 用于成功与连通指示）。
    4. 3D WebGL 视觉重构：由霓虹粒子转向“极简三维几何地形网格 / 极简黑白拓扑雕塑”（Monochromatic Architectural Wireframe & Dynamic Topo-Mesh）。
    5. 重写 Landing Page 布局、双向沙盒、Bento 矩阵、ROI 计算器以及 PRD 3.2 节 8 大工作台的白底黑字极简规范。
- **非目标**：
  - 本阶段不编写前端业务实现代码。
  - 不使用多余花哨色彩干扰核心商贸数据。
