## 1. 需求目标与背景
解决初版 UI 设计文档与 PRD 多语言体系存在出入的问题。SolaFlow AI 本质是“东南亚电商 WhatsApp 多语言订单助手”，必须在 UI 设计规范中强化多语言与本地化交互体系：
- 官网：EN / ID / 中文三语无缝切换，演示印尼语俚语、英语与多语言沙盒。
- 工作台：提供买家多语言会话实时翻译窗（商家中文 ↔ 买家印尼语）、印尼俚语释义气泡、多语言知识库对照矩阵、国家区号多语言工作流分流器、WhatsApp 多语言获批模板管理器。

## 2. MVP 范围及非目标
- **MVP 范围**：
  - 更新 `docs/UI_DESIGN.md`，新增独立的【多语言出海引擎与本地化界面规范】章节。
  - 在官网与工作台（尤其会话队列、知识库、工作流、通道管理）补齐具体多语言 ASCII 线框与字段规范。
  - 维持白底黑字、极简大气、严禁蓝紫色系。
- **非目标**：
  - 本阶段不写后端国际化字典代码。
