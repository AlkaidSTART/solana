# WhatsApp 接入方式文档计划

## 背景与目标
将上一轮 PRD 审查中的 WhatsApp 接入结论整理成独立、可执行的参考文档，保存于 docs/。

## MVP 范围
- 交付 docs/whatsapp-integration-guide.md，比较官方直连、Embedded Signup、官方共存、服务商与非官方方案。
- 说明各方式的关系、适用对象、前置条件、步骤、费用/安全边界、项目推荐路径及测试样例。
- 复用已核验资料，补查官方接入文档；未知项明确列出，不改变 PRD 范围。

## 非目标
不开发代码、不安装依赖、不注册账号、不发送真实消息、不选择或采购 BSP、不更改 PRD/AGENTS。

## 风险与依赖
平台术语、注册版本、费用与资格可能变化；文档不代表本项目已取得账号或通过审核。保留其他任务的文件改动。

## 阶段与测试
1. T1 现状与计划：读取 AGENTS、PRD、现有备忘并检查 git status；预期明确目录规范和原有首发边界。
2. T2 资料与编写：核验官方 Cloud API/Embedded Signup 说明，编写独立指南；预期区分消息通道、授权流程与服务商角色，不混淆 Business App 和 Business Platform。
3. T3 验收：结构断言检查方案、前置/步骤/风险、正常/边界/异常测试、来源及未验证项；校验本地链接和 git diff --check；预期仅新增指南与本需求 plan/result。

## 最终验收标准
指南可供路线选择与试点准备；保留官方来源及核验日期；所有真实接入测试明确未执行；本目录 result.md 记录每阶段结果与遗留。
