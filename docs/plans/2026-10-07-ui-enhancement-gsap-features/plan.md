# 计划：UI 视觉与动效重塑、专业图标库接入、配色升级与功能完善

## 背景与目标
根据用户反馈与产品高标准要求，对 SolaFlow AI 前端进行以下维度的全面升级：
1. **专业图标库全面替代 Emoji**：移除各页面、沙盒、知识库与表格中出现的原生 Emoji（如 🇨🇳, 🇮🇩, 🌐, ✅, ❌, 👁️, 📦, 🚚 等），统一使用 `lucide-react` 精致专业矢量图标与现代语义胶囊。
2. **GSAP 切换过渡动画重塑**：引入 GSAP 3 动画引擎，实现丝滑的 Tab 胶囊滑动下划线、沙盒场景切换 Crossfade、抽屉/弹窗推拉、以及遥测卡片与消息流的 Stagger 缓动进场。
3. **去除多余的 ASCII `//` 符号**：全面清理各页面标题、栏目副标、面包屑与遥测日志中散落的刻板黑客风 `//` 字符，升级为高阶 SaaS 的点状分隔符（`·`）或层级徽章。
4. **配色体系升级，跳出黑白刻板印象**：从原先极端的纯黑白高反差（`#09090B` + `#FAFAFA`）进阶为科技感与商业感兼备的现代调色盘：融入 WhatsApp 生态活力翡翠绿（Emerald `#10B981` / `#059669`）、Solana 原生电光紫/靛蓝（Indigo/Violet `#6366F1` / `#4F46E5`）、告警琥珀橙（Amber `#F59E0B`）与珊瑚玫红（Rose `#E11D48`），配合精致细腻的微渐变背景与发丝线光晕。
5. **各模块功能深度完善**：
   - **订单中心**：完善订单详情抽屉（地址对比、操作时间轴）、快速核验/拒绝 COD、标记挽回、新增“创建模拟订单”功能；
   - **会话与人工队列**：完善双向聊天交互、多语言翻译开关、印尼俚语词典弹窗、接管状态无缝流转；
   - **店铺与通道**：新增通道连通性测试（Webhook Ping 模拟器）、店铺直连绑定弹窗；
   - **多语言知识库**：完善四列多语言对照编辑与 AI 自动翻译模拟；
   - **工作流引擎**：完善规则启停、参数调节抽屉与版本回退机制；
   - **双向遥测沙盒**：交互按钮点击后实现即时意图变化反馈与动效联动。

## 依赖说明 (符合规范第 2 条)
- **新增依赖**：`gsap` 与 `@types/gsap`。
- **必要性**：GSAP 提供了极其平滑的硬件加速补间动画、贝塞尔曲线控制与 Timeline 时间轴编排，能够完美胜任 Tab 滑块无缝追踪、场景切换 Crossfade、卡片入场 Stagger，相比纯 CSS 或简单声明式动画更具控制力与表现力。
- **兼容性**：完全兼容 React 19 与 Next.js 16 App Router（严格在客户端组件或 `useEffect` 中挂载，配合 cleanup，避免 SSR 水合问题）。
- **锁文件**：统一使用 `pnpm add gsap @types/gsap` 维护 `pnpm-lock.yaml`。

## 非目标
- 不对接真实外部生产环境 API 或真实 Meta 商业账号（保持 PRD 规范的隔离 Mock 与高保真交互）。
- 不破坏现有 TypeScript 严格类型与架构分层。

## 阶段拆分
- **阶段 1：依赖安装与 GSAP 动效基建**
  - 安装 `gsap` 及 `@types/gsap`，同步 `pnpm-lock.yaml`。
  - 封装可复用的 GSAP 动效工具/Hook（如 Tab 滑动指示器、淡入微动效、卡片组 Stagger）。
- **阶段 2：全面移除 Emoji，统一替换为 Lucide 专业图标**
  - 重构 `TelemetrySandbox` 交互选项及日志中的 Emoji。
  - 重构 `Knowledge` 多语言旗帜与国家标识，使用精美 SVG/Lucide 图标徽章。
  - 重构 `Settings` RBAC 权限矩阵中的状态符号。
  - 重构 `Workflows` 国家分流表格中的国旗符号。
  - 重构 `Onboarding` 步骤条的勾选符号。
- **阶段 3：清理 ASCII `//` 符号与现代 SaaS 配色升级**
  - 清理所有页面（Landing, Console, Orders, Inbox, Stores, Workflows, Knowledge, Billing, Settings, Onboarding, Login）中标题与标签内的 `//`。
  - 升级 `app/globals.css` 与组件颜色体系，引入翡翠绿、靛蓝、琥珀金等层次丰富的科技配色。
- **阶段 4：GSAP 丝滑切换过渡动画落地**
  - 重构 `Tabs` 组件：使用 GSAP 驱动胶囊或下划线的高性能平滑滑动过渡。
  - 重构 `TelemetrySandbox`：场景切换时内容区域及指标卡片平滑淡入滑入。
  - 在 `Console` 页面、抽屉（Drawer）与模态框（Modal）中注入流畅的进出场过渡。
- **阶段 5：各业务核心功能完善与交互闭环**
  - 订单中心：支持详情抽屉联动核验、快捷新增模拟订单、状态筛选与搜索。
  - 会话工作台：支持发送消息更新状态、俚语高亮词汇查看解释、双向翻译切换。
  - 知识库：支持新增条目、AI 模拟翻译四列对照、保存与发布。
  - 店铺通道：通道 Webhook 实时 Ping 测试抽屉，展现真实延迟与 Payload。
- **阶段 6：代码质量验证与交付验收**
  - 运行 `pnpm exec next typegen && pnpm exec tsc --noEmit`、`pnpm lint` 与 `pnpm build`。
  - 撰写 `result.md` 逐项验证并闭环记录。

## 验收标准
1. 全局无任何原生 Emoji（🇨🇳, 🇮🇩, ✅, ❌ 等），全部替换为 Lucide 图标或高质感徽章。
2. 全局无冗余的 `//` ASCII 字符，界面视觉现代雅致。
3. 颜色告别单纯黑白，具备翡翠绿（WhatsApp）、靛蓝/紫（Solana/AI）、琥珀橙、玫瑰红的和谐高级配色。
4. Tab 切换、场景切换、抽屉弹窗均具备平滑的 GSAP 过渡动画，无闪烁、无跳变。
5. 订单、会话、店铺、知识库等核心功能交互完整可用，具备即时反馈闭环。
6. 构建、类型检查、Lint 零报错。
