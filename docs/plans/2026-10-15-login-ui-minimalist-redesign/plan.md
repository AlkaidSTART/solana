# 登录页面极简优雅风格重构计划 (Login UI Minimalist Redesign)

## 1. 背景与目标
- **背景**：当前 `/login` 页面采用极度生硬的黑白强对比分屏设计（左侧 `AuthShowcase` 为纯黑深邃背景 `bg-zinc-950`，右侧 `AuthCard` 为雪白底色 `bg-white`），且表单各控件普遍采用生硬硬直角 (`rounded-none`)、粗黑实心按钮与高反差边框。用户反馈视觉对比过于刺眼生硬，期望将其重新设计为**现代、优雅、通透的简约风格**。
- **目标**：
  1. 消除页面左黑右白的极端视觉对冲，统一全屏为纯净、通透、低视觉疲劳的现代浅色调（Editorial & Soft Minimalist）。
  2. 保持**所有表单元素、逻辑、输入框、按键、i18n 多语言及校验行为 100% 不变**，仅升级 UI 表现层与空间质感。
  3. 引入克制温和的微曲率圆角系统（`rounded-2xl` 卡片、`rounded-lg` 控件与输入框）、柔和发丝微边框与细腻微阴影，使页面从“生硬工业黑客终端”升级为“高端、精致、简约的国际化跨境电商 SaaS”。

## 2. MVP 范围与非目标
- **MVP 范围**：
  - `app/login/page.tsx`：整体页面布局、导航 Header、底部 Footer 与微质感背景设计。
  - `components/auth/auth-card.tsx`：登录与注册主卡片 UI 重构（模式切换胶囊、输入框质感、6位 OTP 网格、主按钮、密码强度条、提示横条等），不删减任何原有表单逻辑。
  - `components/auth/auth-showcase.tsx`：左侧业务展厅从纯黑 `bg-zinc-950` 重塑为浅色极简商务风格（浅灰/洁白质感、原生浅色 WhatsApp 气泡、精致浅色遥测卡片与 4 大指标面板），与右侧融为一体。
  - `components/auth/oauth-buttons.tsx`：第三方登录按钮微圆角与柔和交互对齐。
- **非目标**：
  - 不修改任何业务规则、接口通信逻辑（Neon Auth、session 建立）。
  - 不增加、不减少任何表单字段或必填项。
  - 不破坏多语言文案字典及状态映射。

## 3. 风险与依赖
- **依赖**：保留已有的 `lucide-react`、`motion/react`、`clsx`、`zustand` 多语言状态。
- **风险**：
  - 6位 OTP 输入框在不同视口下的键盘与自动提交逻辑必须保持完全正常。
  - 浅色 TopoMesh 网格在浅色背景下的对比度和抗锯齿需确保轻盈而不突兀。
  - 必须保证 375px、768px、1440px 视口无横向溢出，符合规范要求。

## 4. 阶段拆分与执行步骤
- **阶段 1：重构 `AuthShowcase` 展厅为浅色极简商务风格**
  - 将暗黑背景 `bg-zinc-950` 改为通透轻盈的浅色雅致基调（`bg-zinc-50/50` 或 `bg-zinc-100/40`），发丝分割线 `border-zinc-200/80`。
  - 重绘 WhatsApp 仿真会话为原生高质感浅色视窗（浅灰/纯白气泡、柔和微绿买家气泡）。
  - 重构 4 列商业指标为极简白底微阴影卡片。
- **阶段 2：重塑 `AuthCard` 登录/注册表单卡片为现代简约质感**
  - 容器升级为 `rounded-2xl border border-zinc-200/80 bg-white/95 shadow-sm`。
  - Tab 切换升级为现代柔和平滑滑块（`rounded-lg`）。
  - 输入框升级为浅底、圆角、自然聚焦过渡样式。
  - 主按钮升级为温润优雅的深灰黑质感按钮，告别生硬粗黑直角。
  - 校验提示横条、密码强度指示条升级为温和圆角与柔和色调。
- **阶段 3：微调 `OAuthButtons` 及 `app/login/page.tsx` 全局架构**
  - 统一 Header、Footer、背景微光与发丝线纹理。
  - 移动端微折叠指标与桌面端双栏完美响应。
- **阶段 4：代码质量检查与全链路验证**
  - 执行 `pnpm lint`
  - 执行 `pnpm exec next typegen && pnpm exec tsc --noEmit`
  - 执行 `pnpm build`
  - 验证表单功能与响应式体验。

## 5. 测试步骤与预期
- **测试 1 (登录/注册模式与子方式切换)**：
  - 步骤：点击“商户登录”与“注册账号”，切换“邮箱动态免密”与“密码登录”。
  - 预期：动效顺滑切换，所有表单项完好显示，无黑白硬冲感。
- **测试 2 (表单输入与校验)**：
  - 步骤：输入邮箱、测试空密码/弱密码、测试 6 位 OTP 输入与删除回退。
  - 预期：各表单交互、校验提示正常显示，视觉柔和简约。
- **测试 3 (多语言切换与全尺寸视口)**：
  - 步骤：切换 中文 / 英文 / 印尼语；测试 375px、768px、1440px 视口。
  - 预期：文案正确渲染，页面排版清爽，无横向滚动条或样式破损。
- **测试 4 (工程质量验收)**：
  - 步骤：运行 lint、tsc、build 命令。
  - 预期：0 报错，0 类型错误，顺利构建。

## 6. 最终验收标准
1. 视觉风格：整体界面呈现纯净、克制、通透的浅色简约风格，彻底消除左黑右白的生硬对冲。
2. 表单元素：100% 保留原有输入字段、按钮、文案、验证码自动提交及第三方登录。
3. 质量闸门：lint、tsc、build 全部通过。
