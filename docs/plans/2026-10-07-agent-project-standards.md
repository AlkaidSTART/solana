# 计划：补齐项目协作规范（AGENTS.md ≤ 200 行）

- 背景：已有 AGENTS.md 仅约束 MVP 流程，缺少完整工程约束。
- 目标：明确技术栈、目录与架构边界、代码风格、安全要求、测试样例、执行命令和交付标准。
- MVP 范围：更新 AGENTS.md；新增本计划；在 result.md 追加分阶段记录。
- 非目标：不实现业务、不安装依赖、不更改现有配置、不把目标架构伪装成已实现服务。
- 依据：package.json、tsconfig.json、eslint.config.mjs、app/、docs/PRD.md、docs/UI_DESIGN.md 及已安装 Next.js 文档。
- 风险/依赖：工作区有其他需求改动；保留其内容及 Next.js 自动区块；框架版本与 API 以实际依赖和本地文档为准。
