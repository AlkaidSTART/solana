# 简约登录注册页面 (Minimal Auth Page) 实施计划

## 1. 背景与目标
- **背景**：SolaFlow AI 现有的 `/login` 页面仅包含基础的免密登录卡片，缺少注册（Sign Up）入口与表单、缺少密码登录选项、缺少验证码倒计时/重发/粘贴体验，且多语言与国际化未完全打通。
- **目标**：打造一个严格符合 `docs/UI_DESIGN.md`（瑞士国际主义极简黑白、1px 发丝线、大留白、严禁蓝紫赛博色）与 `ui_design/09-auth-onboarding/README.md` 规范的**简约登录与注册页面**。
- **核心体验**：
  1. 提供【商户登录】与【商户注册】双模式切换（Tabs / 底部快捷切换）；
  2. 登录支持【邮箱免密验证码 (6位 OTP)】与【账号密码】双选项；
  3. 6 位验证码输入支持数字单格、自动切焦、退格回退、剪贴板粘贴 6 位自动回填、60 秒倒计时与重新发送；
  4. 注册流程包含工作邮箱、店铺名称、密码设置、目标出海市场选择及协议勾选，注册成功后引导前往 6 步入驻向导（`/onboarding`）；
  5. 保留“一键演示商户直通”入口，方便评审与测试；
  6. 严格黑白单色风格、响应式适配（375px/768px/1440px）与无障碍 (a11y) 支持。

## 2. MVP 范围
- **页面路由**：
  - 主路由：`/login`（支持 `?mode=login` 与 `?mode=register` 参数，默认登录模式）；
  - 辅助路由：`/register`（透明重定向至 `/login?mode=register` 或直接共享组件，方便直接访问注册链接）。
- **组件与交互**：
  - 顶部导航：品牌 SolaFlow AI 标志、出海业务副标、多语言切换下拉/胶囊、返回首页入口；
  - 身份认证卡片主体：
    - 顶部模式切换（登录 Sign In / 注册 Sign Up）；
    - 登录视图：免密动态码（输入邮箱 -> 发送验证码 -> 6位分格输入 -> 校验登录）+ 密码登录模式；
    - 注册视图：工作邮箱、商户店铺名、出海市场（印尼/泰国/马来/菲律宾等）、密码及确认、协议同意；
    - 交互状态：空值校验、非法邮箱提示、验证码倒计时器、加载状态（防止连击）、成功 toast/状态卡片；
    - 演示直通：一键载入测试账号凭据，一键快速进入控制台 `/console`；
  - 底部页脚：合规声明、Meta BAA 商业协议提示、Solana 结算安全标示与版权年份。

## 3. 非目标 (Out of Scope)
- 真实第三方 OAuth 嵌入（如 Google / Meta 弹窗鉴权在此版本不做外部重定向，保持原生邮箱 OTP + 密码模式）；
- 复杂的多租户组织架构审批（属于控制台 RBAC 范围，入驻期保持极简）。

## 4. 风险与依赖
- **依赖**：`clsx`, `tailwind-merge`, `lucide-react`, `motion` 或 `gsap`，现有 `components/ui` 基础组件。
- **风险**：
  - 现有工作区中 `app/console/stores/page.tsx` 存在一处既有语法错误（遗漏 `clsx` 导入），执行完整 build 时需确保不破坏已有改动；
  - 客户端组件的水合（Hydration）需保证 SSR/客户端一致（尤其时钟或倒计时）。

## 5. 阶段拆分
- **阶段 1：设计与结构规划**：定义多语言字典、登录注册状态机类型（Mode: login/register, LoginType: otp/password）。
- **阶段 2：开发核心登录/注册页面组件**：实现 `/login/page.tsx` 与 `/register/page.tsx`，具备完整表单验证、6 位 OTP 交互、倒计时、演示快速通道。
- **阶段 3：多语言、主题与动效打磨**：对齐 `docs/UI_DESIGN.md` 黑白极简令牌，加入细腻的输入反馈与平滑切换动效。
- **阶段 4：质量检查与全链路验证**：修复既有类型缺陷，执行 TypeScript 类型检查、ESLint、构建验证，并执行多尺寸响应式检查。

## 6. 测试用例与预期
- **T1: 模式切换 (Login <-> Register)**：点击 Tabs 或“还没有账号？立即注册”链接，平滑切换表单内容，URL 参数与标题同步更新。
- **T2: 免密验证码流程**：
  - 输入无效邮箱，提示“请输入有效的商户工作邮箱”；
  - 输入有效邮箱点击发送，触发 60s 倒计时，展开 6 位输入框；
  - 粘贴 6 位数字，自动分流至 6 个单元格并可提交；
  - 错误验证码给出醒目提示；输入正确验证码进入 `/onboarding`。
- **T3: 密码登录流程**：切换至“密码登录”，输入邮箱和密码，可切换明文/密文，校验通过进入系统。
- **T4: 注册流程**：填写邮箱、店铺名称、出海市场、密码并同意条款，点击注册进入 `/onboarding` 流程。
- **T5: 一键演示商户通道**：点击“一键以演示商户身份直接进入控制台”，平滑跳转 `/console`。
- **T6: 移动端 (375px) 与大屏 (1440px) 响应式测试**：布局无横向溢出，卡片居中，发丝线分明。

## 7. 最终验收标准
1. `/login` 和 `/register` 页面均能正常渲染且风格高度契合 Swiss Architectural Minimalist；
2. 登录与注册功能交互完整，包含各种边界输入校验与 loading 状态；
3. `pnpm exec next typegen && pnpm exec tsc --noEmit` 检查通过；
4. `pnpm build` 顺利通过；
5. `result.md` 完整记录执行情况与验收结论。
