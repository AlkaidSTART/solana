# 需求计划：登录页全新极简居中高奢重构 (Login Page Minimalist Centered Redesign)

## 1. 背景与目标
- **背景**：原有登录页 (`app/login/page.tsx`) 采用左右分屏布局，左侧嵌入了包含 WhatsApp 仿真对话气泡、营销转化数据与客户证言的展示组件 (`AuthShowcase`)。从专业产品 UI/UX 设计角度审视，该组件属于 Landing Page 营销物料，置于商户高频使用的认证登录页面造成了严重的视觉干扰、主次颠倒与跨设备（特别是中等分辨率笔记本和移动端）空间挤压溢出。用户明确要求以专业设计师角色彻底移除该组件并重新设计登录页。
- **目标**：参考国际顶级科技与企业级 SaaS（Linear、Stripe、Supabase、Clerk）的设计美学，将登录页重塑为**极简居中聚焦高奢控制台 (Minimalist Centered Auth Console)**。彻底移除左侧假对话框与营销卡片，利用通透层叠的发丝网格底纹与微光晕营造沉浸感，突出核心认证卡片、极速流转交互（OTP/密码/OAuth）与底层企业合规背书（Meta BAA 直连、Solana Pay 结算、端到端加密），实现多视口 0 溢出无滚动条的极速认证体验。

## 2. MVP 范围与非目标
- **MVP 范围**：
  1. `app/login/page.tsx`：彻底移除 `AuthShowcase` 展厅及分屏布局；采用居中高质感布局，引入极度克制的微环境渐变光晕与精密建筑学发丝网格；构建微型悬浮顶栏（品牌 Logo、`META BAA DIRECT // 99.99% UPTIME` 运行状态呼吸灯、无 Emoji 的矢量语言切换器与返回链接）与底部信誉合规栏（Meta BAA Direct、Solana Pay USDC、256-bit 加密及东南亚边缘节点低延迟数据）。
  2. `components/auth/auth-card.tsx`：全面升级卡片质感，维持已有的安全能力（Neon Auth 登录、OTP 6 位自动提交、密码强度指示器、OAuth 按钮与记住邮箱）。优化其在居中视口下的尺寸比例、内边距、圆角与微阴影，使视线极度聚焦。
  3. `app/register/page.tsx`：同步清理该页面对 `AuthShowcase` 的引用，保持与登录页相同的居中高定设计语言，预设为开通商户账号模式。
  4. 多视口无溢出契约：针对 375px（移动端）、768px（平板）、1024px/1366px（常见笔记本）、1440px/1920px（桌面大屏）进行像素级适配，全屏自适应，杜绝不必要的页面滚动条。
  5. 多语言完整适配：`zh_CN`、`en_US`、`id_ID` 三种语言下文本排版与间距无折行错位。
  6. 测试与交付闸门：维护并补充登录页视口与卡片行为的自动化测试，执行 `pnpm lint`、`tsc --noEmit`、`pnpm test` 与 `pnpm build` 确保 100% 绿灯。
- **非目标**：
  1. 不改动底层用户认证协议、API Handlers、数据库会话及第三方 Neon Auth 配置。
  2. 不更改控制台、设置、知识库或入驻向导等非认证路由代码。

## 3. 风险与依赖
- **风险 1：居中布局在极端矮屏（如高度 < 550px）下的可用性**
  - *应对方案*：采用 `h-dvh max-h-dvh flex flex-col justify-between` 视口契约，主体区域设置 `min-h-0 overflow-y-auto`，默认常规屏幕居中无滚动，矮视口下自动激活平滑滚动保护。
- **风险 2：注册模式字段较多时居中卡片的高度控制**
  - *应对方案*：注册表单采用精炼双列响应式栅格（店铺名称与目标市场、密码与确认密码在支持时双列排布），合理控制垂直高度，确保整体卡片高度在各端舒适呈现。
- **风险 3：国际化文案长度差异（如印尼语较长）**
  - *应对方案*：采用弹性 flex 布局与微缩文字层级（`text-[10px]/text-xs`），确保中英印尼三语无论在移动端还是桌面端均能整洁展现。
