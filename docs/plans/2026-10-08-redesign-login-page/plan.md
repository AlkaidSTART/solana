# 需求计划：重新设计高定商业级登录与鉴权页 (Redesign Luxury Login Page)

## 1. 背景与目标
- **背景**：当前登录页面（`/login`）过于简约单薄（单调的单列居中小白框、缺乏品牌氛围、缺乏出海电商业务感知），无法展现 SolaFlow AI 作为面向东南亚跨境电商的 Awwwards 级别现代 SaaS 产品的科技感、商业信任感与高级品质。
- **目标**：
  1. 重构登录页面为具有“顶级 SaaS 质感”的沉浸式双栏分屏架构（大屏双栏分屏展厅，小屏紧凑高级单屏）；
  2. 左侧构建高定品牌叙事与东南亚实时商业遥测展厅（包含发丝网格、单色拓扑动效、WhatsApp 订单智能追单与 COD 防损实况模拟卡片、跨国节点低延迟遥测指标及商户信用背书）；
  3. 右侧精细雕琢现代高质感鉴权交互中心（免密 OTP 6 单元格精密输入、账号密码登录、商户注册向导接入、一键填入演示凭据、一键进入演示工作台、三语无缝切换、多段发丝密码强度条等）；
  4. 严格遵守视觉规范：白底深黑铅字、1px 发丝几何线（#E4E4E7）、功能性翡翠绿（#059669 / #10B981）、严禁蓝紫霓虹；
  5. 完整保持所有业务逻辑不变，保证国际化（中/英/印尼）、可访问性、自适应（375px / 768px / 1440px）、以及既有单元测试 100% 通过。

## 2. MVP 范围
- **页面与组件**：
  - `app/login/page.tsx`：升级为全屏沉浸式双栏分屏架构布局，集成左侧出海商业遥测展厅与右侧鉴权中心，完善顶部导航与页脚。
  - `components/auth/auth-card.tsx`：精细重构鉴权卡片，保持完整的 OTP / 密码登录与注册模式，提升输入框、6 单元格 OTP、密码强度显示、一键演示等视觉与交互质感。
  - `components/auth/auth-showcase.tsx`（新增）：左侧出海电商实时遥测展厅组件，展示 WhatsApp 真实追单会话模拟、COD 防损核验、跨国节点健康状态、关键指标数据胶囊与商户背书。
  - `app/register/page.tsx`：同步使用新的高级分屏布局或卡片配置，确保从注册入口进入体验一致。
- **核心交互与状态**：
  - 支持免密 OTP 登录（60s 倒计时、6 格输入、自动对焦、粘贴剪贴板、演示码 892104）；
  - 支持账号密码登录（显示/隐藏明文、忘记密码跳转）；
  - 支持新商户注册（店铺名、目标市场、密码强度实时计算、条款勾选、+100 试用 Credits）；
  - 一键填充演示凭据（邮箱/演示码/密码快速灌入）；
  - 一键直达控制台（快捷演示通道）；
  - 多语言切换（中文、英文、印尼语实时生效，与 `useAppStore` 联动）。

## 3. 非目标 (Out of Scope)
- 不新增后端鉴权路由或替换 `lib/server/auth/**` 的实际逻辑；
- 不引入蓝紫色系或未授权的外部样式库；
- 不改动已生效的入驻向导流程（`/onboarding`）逻辑。

## 4. 风险与依赖
- **3D / 动效性能与降级**：遥测展厅动效需支持 `prefers-reduced-motion`，低功耗平滑运行，不引起卡顿；
- **移动端响应式布局**：在 375px（移动端）和 768px（平板）下，左侧展厅需优雅隐藏或折叠，确保右侧表单与输入完全无横向溢出。
- **OTP 粘贴与单元格焦点**：需保持现有单元格粘贴和自动跳转逻辑，避免重构引入回归。

## 5. 阶段拆分
- **阶段 1**：创建出海商业实时遥测展厅组件 `components/auth/auth-showcase.tsx`，融入发丝网格、WhatsApp 真实模拟会话卡片、COD 防损指标与商户背书。
- **阶段 2**：升级重构 `components/auth/auth-card.tsx`，采用高级建筑学发丝层级、精雕细琢的 Tab、输入框、6 位 OTP 聚焦效果与状态反馈。
- **阶段 3**：重构 `app/login/page.tsx` 和 `app/register/page.tsx`，组装沉浸式双栏分屏布局，完善响应式视口适配（375px / 768px / 1440px）与多语言联动。
- **阶段 4**：执行代码检查、单元测试、构建验证（`pnpm lint`、`tsc --noEmit`、`pnpm test`、`pnpm build`），完成验收。

## 6. 各阶段测试步骤、输入及预期
- **测试 T1 (展厅组件)**：在多语言（中文、英文、印尼语）下渲染展厅，验证指标卡片、WhatsApp 对话模拟、时区节点展示无错位。
- **测试 T2 (OTP 交互)**：输入邮箱，点击发送，填入 892104，测试粘贴 6 位数字，测试退格删除，测试提交跳转。
- **测试 T3 (密码与注册模式)**：切换至密码模式与注册模式，测试密码强度指示器、表单校验、一键填入演示凭据。
- **测试 T4 (快捷通道)**：点击“一键以演示商户身份直接进入控制台”，验证平滑跳转至 `/console`。
- **测试 T5 (工程闸门)**：运行 `pnpm test`、`pnpm lint`、`tsc --noEmit`、`pnpm build`，必须 100% 无错误无警告。

## 7. 最终验收标准
1. 页面视觉展现出高级现代科技 SaaS 气质，彻底摆脱单调简陋感；
2. 严格契合极简黑白、1px 发丝线、功能绿的整体设计规范；
3. 桌面端双栏分屏（遥测展厅 + 鉴权中心），移动端自适应紧凑高级单屏；
4. 免密 OTP、密码登录、注册、一键演示等全部功能正常可用；
5. 全面覆盖多语言（中文/英文/印尼语）；
6. 所有构建与自动化测试均通过。
