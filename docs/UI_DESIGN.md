## 1. 视觉设计哲学：极简白底与建筑学编排

### 1.1 核心设计理念：Less, But Better (少，却更好)
东南亚跨境电商场景往往复杂琐碎（多语言口音、COD 拒签痛点、物流丢包、汇率损耗）。SolaFlow AI 的 UI 设计不通过浮夸的蓝紫色调制造虚假科技感，而是以**极简白底黑字、精湛版式节奏与真实数据密度**，建立强大的商业信任感：

1. **Pure Paper White Canvas (纯白纸张基底)**：
   全站以纯白（`#FFFFFF`）和微妙的冷暖灰度（`#FAFAFA`、`#F4F4F5`）为基底，呼吸感充足，消除长时间阅读疲劳。
2. **Ink-Black Architectural Typography (黑铅铸字张力)**：
   以深黑（`#09090B`）为最高视觉权重，借助严密的字号跨度（80px 到 11px）与收紧的字间距（`tracking-tighter`），创造如殿堂级出版物般的理性之美。
3. **1px Hairline Precision (发丝线空间界定)**：
   摒弃笨重的实体投影与厚重阴影，使用 1px 的超细灰线（`#E4E4E7`）划分网格单元，所有数据框线如建筑图纸般规整。
4. **Restrained Functional Accents (克制的功能性强调)**：
   **严禁蓝紫**。仅保留单一功能性深翡翠绿（`#059669` / `#10B981`），用于 WhatsApp 连通状态与成功对勾；其余所有元素均保持黑、白、灰度。

## 2. 设计系统与全局黑白令牌

### 2.1 极简色彩令牌体系 (Monochrome Tokens)

```css
/* Base Canvas & Paper Surfaces */
--bg-canvas:         #FFFFFF; /* 纯白主画布 */
--bg-subtle:         #FAFAFA; /* 浅灰二级底色 */
--bg-muted:          #F4F4F5; /* 三级卡片与标签底色 */
--bg-elevated:       rgba(255, 255, 255, 0.85); /* 毛玻璃高阶面板 */

/* Borders & Hairlines */
--border-hairline:   #E4E4E7; /* 1px 极细发丝线 */
--border-subtle:     #EEEEEE; /* 极浅分割线 */
--border-contrast:   #18181B; /* 高对比激活线 */

/* Typography & Ink Levels */
--ink-primary:       #09090B; /* 深度纯黑，主标题与关键数据 */
--ink-secondary:     #27272A; /* 次级正文与小标题 */
--ink-muted:         #71717A; /* 辅助说明、时间戳、次要标签 */
--ink-faint:         #A1A1AA; /* 占位符、弱化元信息 */

/* Functional Single Accents (无蓝紫，严格限定) */
--functional-green:  #059669; /* WhatsApp 状态与通过验证 */
--functional-red:    #E11D48; /* COD 高危风险预警与取消 */
--functional-amber:  #D97706; /* 待处理与人工介入提示 */
```

### 2.2 字体排印规范 (Typography Hierarchy)
- **西文标题 (Headings)**：`Geist Sans` 或 `Helvetica Neue`，严谨无衬线，字重 `800 ExtraBold`、`700 Bold`，字间距 `-0.04em`。
- **正文 (Body)**：`Geist Sans` / `Plus Jakarta Sans`，字重 `400 Regular`、`500 Medium`，行高 `1.6`。
- **微数据与链上哈希 (Monospace)**：`Geist Mono` / `JetBrains Mono`，字重 `500 Medium`，全大写或等宽对齐。

#### 阶梯字号规范 (Type Scale)
| 令牌 | 尺寸 / 行高 | 字重 | 用途 |
| :--- | :--- | :--- | :--- |
| `text-display-2xl` | 80px / 1.02 | 800 | 官网主视觉巨型标语（极黑、紧缩） |
| `text-display-xl`  | 52px / 1.08 | 700 | 章节主标题（纯黑、大留白） |
| `text-display-lg`  | 36px / 1.15 | 700 | Bento 模块标题、核心指标数字 |
| `text-body-lg`     | 18px / 1.6  | 400 | 引言导语、价值主张段落 |
| `text-body-base`   | 14px / 1.5  | 400 | 对话气泡、表格正文、说明文字 |
| `text-mono-xs`     | 11px / 1.4  | 500 | 交易哈希、Slot 槽位、系统日志 |

## 3. 3D WebGL 极简单色拓扑雕塑规范

在纯白底色的视觉环境下，3D 资产摆脱繁复发光装饰，采用**极简三维单色拓扑地貌网格（The Monochromatic Kinetic Topo-Mesh）**，兼具工业设计与雕塑质感。

```
              [ Three.js Monochromatic Topo-Mesh ]
                      ____________________
                    /  \  \  \  \  \  \  \ \
                   / /\ \  \  \  \  \  \  \ \
                  / /  \ \__\__\__\__\__\__\ \    <-- Black Hairline Wireframe (#18181B)
                 | | CGK    \      \   BKK  | |   <-- Precision Geo-Ticks
                 | |  *------\------\---*   | |
                  \ \  \      \ SIN  \ /   / /
                   \ \__\______\*_____\___/ /
                    \______________________/
              [ Clean White Background: #FFFFFF ]
```

### 3.1 3D 场景技术参数
1. **纯白环境光与画布**：
   - 画布背景透明或纯白（`#FFFFFF`），开启双重线性抗锯齿（`antialias: true`）。
   - 环境光（AmbientLight）：强度 `1.0`，纯白光。
   - 单一方向微阴影（DirectionalLight）：轻柔投影，产生如石膏雕塑般的柔和层次。
2. **单色拓扑网格几何体 (Monochrome Parametric Wireframe)**：
   - 几何形态：基于东南亚地理经纬度起伏的极简三维流线雕塑网格。
   - 材质：`THREE.LineBasicMaterial`，线条颜色为纯黑铅灰（`#18181B`），线宽 `1.0`，无刺眼杂光。
   - 数据节点：仅在印尼雅加达 (CGK)、泰国曼谷 (BKK)、新加坡 (SIN)、菲律宾马尼拉 (MNL) 和深圳 (SZX) 设置黑色微实心圆点（直径 $1.2$）与 1px 细线引出标注文字。
3. **交互反馈**：
   - 鼠标悬停（Hover）：网格随鼠标位置平滑产生如水波或纸张微张力形变（Damping 阻尼系数 $0.05$）。
   - 旋转拖拽：轻量惯性平移，松手后自然缓慢巡航。
   - 降级与节能：超出视口自动停止帧渲染，保证整机风扇静音与 60 FPS 恒定运行。

### 5.1 交互气泡与遥测细节
1. **WhatsApp 对话气泡**：
   - 机器人发送：底色纯白 `#FFFFFF`，1px 灰线 `#E4E4E7`，文字 `#09090B`。
   - 用户发送：底色浅灰 `#F4F4F5`，文字 `#09090B`。
   - 状态标识：纯深灰时间戳与深翡翠绿双对勾（`✓✓`）。
2. **神经决策遥测控制台**：
   - 彻底摒弃荧光紫色背景，采用浅灰卡片（`#FAFAFA`）与细黑文字。
   - 风险进度条（Risk Bar）：纯黑细线边框，内部填充由细黑斜线阴影或深色墨块表示，低危为深绿，高危为深红，中间状态为中灰。

| **4. 订单中心 (Orders)** | 订单全生命周期与履约核实 | - 原平台订单号、原平台状态、同步延迟时间<br>- SolaFlow 工作流处理状态（待检查、排队中、已发消息、已回复）<br>- **COD 确认结果**（明确确认、改址申请、取消、失联、超时）<br>- 原平台订单直达跳转超链接（WooCommerce / Shopify） |
| **5. 会话与人工队列 (Inbox & Human Handover)** | 智能客服与人工紧急接管 | - 买家当前语言识别（印尼语、泰语、英语）<br>- 24 小时客户服务窗口倒计时（防止窗口关闭违规）<br>- 人工接管状态开关（AI 自动模式 / 客服人工处理中）<br>- 关联的订单详情抽屉、改址或取消操作复核日志 |
| **6. 知识库管理 (Knowledge Base)** | 东南亚多语言智能客服大脑 | - FAQ 与商品来源同步状态（从商品描述与尺码表抽取）<br>- 知识库冲突项警告（如两个文档尺码标准不一致）<br>- 管理员人工审核与修订记录 |
| **7. 财务充值中心 (Billing & Solana Pay)** | 链上清算流水与服务费点数 | - 当前订阅周期有效期、Credits 分类余额（赠送额度 / 购买额度）<br>- 逐笔消费流水（发送消息扣费、退款返还）<br>- **Solana Pay 快速充值面板**：支持 25, 50, 100 USDC 档位，实时链上状态核查与重复入账防重证明（Idempotency Key） |
| **8. 报表与设置 (Analytics & Settings)** | 指标归因与安全合规 | - KPI 口径说明、样本量与观察窗口配置<br>- 团队成员权限（商户所有者、管理员、客服、财务）<br>- 数据导出与买家数据彻底删除申请（GDPR / 隐私法规支持） |

## 9. 动效编排：物理阻尼与克制微交互

在白底黑字体系下，多余的夸张动效会破坏严肃商业质感。全站动效遵循**瑞士手表机械般的精准阻尼**：

- **进场微动效 (Stagger Entry)**：
  元素进入时不产生大幅旋转或漂移，仅使用纯粹的垂直微位移（$Y: 12\text{px} \to 0$）与不透明度过渡（$0 \to 1$），时间 $\le 240\text{ms}$。
- **缓动曲线 (Easing Curve)**：
  采用自然物理阻尼 `cubic-bezier(0.16, 1, 0.3, 1)`。
- **按钮按压反馈 (Press State)**：
  点击瞬间轻微下压 `scale(0.98)`，边框色由浅灰转为深黑（`#18181B`）。
- **页面滚动交互 (Scroll-Tracking)**：
  不使用强制惯性滚动手柄（Smooth-scroll hijacking），完全尊重原生浏览器滚动手感与系统设置。

## 10. 多语言排版、无障碍 (a11y) 与 Awwwards 评审指标自检

### 10.1 本地化长文本排版安全防线
1. **印尼语 (Bahasa Indonesia)**：
   长单词（如 *Konfirmasi Alamat Pengiriman*）强制开启 `hyphens: auto; word-break: break-word;`，在移动端小屏幕（375px）上杜绝文字溢出容器。
2. **泰语 (Thai)**：
   泰语上下标声调符号丰富，正文统一保证 `line-height >= 1.6`，防止上下标符号被发丝线截断。
3. **中文 (商家端)**：
   采用标准思源黑体 / PingFang SC，字符间距中正平稳，与西文字体和谐混排。

### 10.2 无障碍 (WCAG AA) 合规性
- **黑白极限对比度**：纯黑文本（`#09090B`）在纯白背景（`#FFFFFF`）上的对比度高达 **19.8:1**，远超 WCAG AAA 级的 7:1 要求。
- **次要灰字可读性**：次级中灰（`#71717A`）在纯白底色上的对比度为 **4.6:1**，严格符合 WCAG AA 标准。
- **全键盘可访问**：所有按钮与选项均提供 `focus-visible: outline 2px solid #09090B; outline-offset: 2px`，键盘焦点清晰可见。
